# AI Researcher Learning Path

This repository is my personal lab for becoming an AI researcher through deep, hands-on practice.

Instead of only reading papers, I study by rebuilding their core ideas from scratch, testing them, and writing clear notes about what I learned.

This reposirory is simply exist for learning purpose and to track my learning progress  and keep my notes up to date.

The goal is simple:

- Understand foundational papers at a technical level.
- Implement their core modules myself.
- Build research intuition through repeated practice.

## Why This Repository Exists

Learning research-level AI requires more than passive reading. This repo is where I actively learn by combining:

- Paper reading
- Mathematical understanding
- Implementation from scratch
- Experimentation
- Reflection and notes

Over time, this should become a structured knowledge base of key AI ideas and working implementations.

## How I Study Each Paper

For each paper, I follow a repeatable workflow:

1. Read the paper and identify the core contribution.
2. Break the method into small building blocks.
3. Implement each building block from scratch.
4. Run small experiments to verify behavior.
5. Write notes on what worked, what was confusing, and what I learned.
6. Capture open questions for deeper research later.

This process helps me move from "I read it" to "I can explain and reproduce it."

This repository is a living document of learning, not a finished product.
